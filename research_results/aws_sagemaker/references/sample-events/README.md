# Sample events

Anonymized JSON for structured SageMaker records. Account `111122223333`, bucket `example-bucket`, and role `ExampleSageMakerRole` replace values from the AWS examples.

Files **without** the `constructed-` prefix are anonymized copies of an official example. A few of those copies replace AWS placeholder strings (`"status"`, `"another status... GO"`) with a real enum value so the JSON is usable. That substitution is noted below.

Files **with** the `constructed-` prefix were built from a published schema or API shape because AWS did not publish a complete, valid example. They are not captured traffic.

`constructed-feature-store-offline-row.json` is **not a log**. It only illustrates the three system columns AWS adds to offline-store Parquet plus two user features. AWS does not publish a timestamp encoding for those columns.
