## Categorization

| Source record                                                   | event.kind | event.category                                                                                               | event.type                                                                                                                                | event.outcome                                                                                                                      |
| --------------------------------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Training / processing / transform / endpoint container log line | `event`    | `[process]`                                                                                                  | `[info]`, or `[error]` when the line is an `ERROR` / `AlgorithmError` / Python traceback frame                                            | `failure` only when the line is an error. Omit otherwise.                                                                          |
| Notebook or Studio lifecycle / Jupyter line                     | `event`    | `[process]`                                                                                                  | `[info]` or `[error]`                                                                                                                     | same rule                                                                                                                          |
| Ground Truth worker-activity JSON                               | `event`    | `[process]`                                                                                                  | `[info]`                                                                                                                                  | omit unless the record has a documented failure status                                                                             |
| CloudWatch metric datapoint                                     | `metric`   | `[host]` for CPU, memory, GPU, disk. `[process]` for invocations, errors, latency, pipeline execution counts | omit                                                                                                                                      | omit                                                                                                                               |
| EventBridge job or endpoint state change                        | `event`    | `[process]`                                                                                                  | `[start]` for `InProgress` / `Creating` / `Updating`; `[end]` for a terminal status; `[change]` always; `[error]` when status is `Failed` | `success` for `Completed` / `Succeeded` / `IN_SERVICE`; `failure` for `Failed` / `RollingBack`; omit for `Stopping` / `InProgress` |
| EventBridge pipeline execution or step                          | `event`    | `[process]`                                                                                                  | `[start]`, `[end]`, `[change]`, `[error]` using the same status rule                                                                      | `success` for `Succeeded`; `failure` for `Failed`                                                                                  |
| Model Monitor `constraint_violations.json`                      | `alert`    | `[process]`                                                                                                  | `[info]`                                                                                                                                  | `failure`                                                                                                                          |
| Endpoint data-capture JSONL                                     | `event`    | `[process]`                                                                                                  | `[info]`                                                                                                                                  | omit. This is a sampled inference payload, not an error.                                                                           |

`event.action` on state events should be the EventBridge `detail-type` string (for example `SageMaker Training Job State Change`), not a shortened verb.

`cloud.provider` is `aws` on every stream. `cloud.service.name` should be the constant `sagemaker` so this package does not collide with `aws_bedrock`, a future `aws_stepfunctions`, `aws_glue`, or `aws_athena` package. `event.module` is `aws_sagemaker`. `event.dataset` is `aws_sagemaker.<stream>`.

## Logs stream (`aws-cloudwatch`)

The CloudWatch input already supplies log-group and stream metadata. Keep those AWS fields. Do not invent a JSON schema for the message body.

| Source                                                              | ECS or custom field                                                                                  | Type            | Notes                                                                                                                                                                                                 |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CloudWatch event timestamp                                          | `@timestamp`                                                                                         | date            | Primary. The bracket time inside a built-in algorithm line (`[10/16/2017 23:45:17 ERROR …]`) is not reliable across BYOC containers.                                                                  |
| Bracket time inside built-in algorithm lines, when the grok matches | `event.created`                                                                                      | date            | Optional. Format `MM/dd/yyyy HH:mm:ss`. Many lines have no such prefix.                                                                                                                               |
| `logGroup`                                                          | `aws.cloudwatch.log_group` (input) and `log.logger`                                                  | keyword         | Also derive `aws_sagemaker.workload` from the group name: `training`, `processing`, `transform`, `endpoint`, `notebook`, `studio`, `compilation`, `labeling`, `groundtruth`, `inference_recommender`. |
| `logStream`                                                         | `log.file.path` or the input's stream field                                                          | keyword         | Also split into custom fields below.                                                                                                                                                                  |
| Stream `[job]/algo-[n]-[epoch]` on TrainingJobs                     | `aws_sagemaker.job.name`, `aws_sagemaker.instance.id`                                                | keyword         | `algo-[n]` is the cluster member, not an EC2 instance id.                                                                                                                                             |
| Stream `[variant]/[instance-id]` on an endpoint group               | `aws_sagemaker.endpoint.name` (from the log group suffix), `aws_sagemaker.variant.name`, `host.name` | keyword         | Endpoint name is the last path segment of `/aws/sagemaker/Endpoints/[EndpointName]`.                                                                                                                  |
| Raw line                                                            | `message`                                                                                            | match_only_text | Preserve original.                                                                                                                                                                                    |
| `ERROR`, `AlgorithmError`, `Traceback`                              | `error.message`                                                                                      | match_only_text | Copy the line. `log.level` = `error` when matched.                                                                                                                                                    |
| `Train_error=…` style metric lines                                  | do not map as metrics on this stream                                                                 | —               | SageMaker already emits the regex match as a CloudWatch metric in `/aws/sagemaker/TrainingJobs`. Collect that on the metrics stream.                                                                  |

`related.hosts` can take `host.name` when the stream contains an instance id. Training `algo-1` is not a hostname. Do not put it in `related.hosts`.

There is no source IP, user, or hash on container stdout. Do not GeoIP this stream.

## Metrics stream (`aws/metrics`)

Follow the AWS integration metric document shape: one document per datapoint, dimensions flattened.

| Source                             | ECS or custom field                                               | Type                     | Notes                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------------- | ----------------------------------------------------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Datapoint timestamp                | `@timestamp`                                                      | date                     | CloudWatch returns Unix seconds.                                                                                                                                                                                                                                                                                                                                                        |
| Namespace                          | `aws_sagemaker.metrics.namespace`                                 | keyword                  | Preserve exact case. `AWS/SageMaker` and `AWS/Sagemaker/ModelBuildingPipeline` are different strings.                                                                                                                                                                                                                                                                                   |
| Metric name                        | `aws_sagemaker.metrics.name`                                      | keyword                  | Also copy the numeric value to a typed field when the name is in the v1 allow-list (`Invocations`, `Invocation4XXErrors`, `Invocation5XXErrors`, `InvocationModelErrors`, `ModelLatency`, `OverheadLatency`, `CPUUtilization`, `MemoryUtilization`, `GPUUtilization`, `GPUMemoryUtilization`, `DiskUtilization`, `ExecutionFailed`, `StepFailed`, `ExecutionDuration`, `StepDuration`). |
| Value                              | `aws_sagemaker.metrics.value`                                     | double, gauge or counter | Latency in `AWS/SageMaker` is **microseconds**. Pipeline durations are **milliseconds**. `ClientLatency` on Inference Recommender is **milliseconds**. Do not convert in the field name; record `aws_sagemaker.metrics.unit`.                                                                                                                                                           |
| `EndpointName`                     | `aws_sagemaker.endpoint.name`                                     | keyword, dimension       |                                                                                                                                                                                                                                                                                                                                                                                         |
| `VariantName`                      | `aws_sagemaker.variant.name`                                      | keyword, dimension       |                                                                                                                                                                                                                                                                                                                                                                                         |
| `InferenceComponentName`           | `aws_sagemaker.inference_component.name`                          | keyword, dimension       |                                                                                                                                                                                                                                                                                                                                                                                         |
| `Host`                             | `aws_sagemaker.host`                                              | keyword, dimension       | Training host is `[job]/algo-[n]`. Processing `Host` uses `algo-[n]` while the log stream uses `[hostname]-[epoch]`. Do not join them on the raw string.                                                                                                                                                                                                                                |
| `TrainingJobName`                  | `aws_sagemaker.job.name`                                          | keyword, dimension       | Algorithm regex metrics only.                                                                                                                                                                                                                                                                                                                                                           |
| `PipelineName`, `StepName`         | `aws_sagemaker.pipeline.name`, `aws_sagemaker.pipeline.step.name` | keyword, dimension       | Pipelines only. Not Step Functions.                                                                                                                                                                                                                                                                                                                                                     |
| `JobName` on Inference Recommender | `aws_sagemaker.job.name`                                          | keyword                  |                                                                                                                                                                                                                                                                                                                                                                                         |

`event.duration` is not a substitute for `ModelLatency`. Latency is a gauge of the interval, already in microseconds, and belongs on the metric value. If a later pipeline copies `ModelLatency` into `event.duration`, it must stay in microseconds (ECS `event.duration` is nanoseconds in some stacks and microseconds in others — check the pinned ECS version before copying). Safer: leave latency only on `aws_sagemaker.metrics.value` with `unit: microseconds`.

## Geo enrichment

No v1 field is a client or server IP. Do not add a `geoip` processor. Data-capture bodies can contain arbitrary customer text that happens to look like an IP. Do not scan them.

## Fields that must stay custom

Anything under `detail` that is SageMaker-specific (`SecondaryStatus`, `HyperParameters`, `FailureReason` when duplicated for search, pipeline `currentStepStatus`, monitor check type) goes in `aws_sagemaker.*`. Do not place those under `aws.*` from the shared AWS package, or the two packages will fight over the same field names when both are installed.

`aws.cloudwatch.*` fields written by the `aws-cloudwatch` input are the exception. They are input metadata, already defined by the AWS input, and should be left as the input emits them.
